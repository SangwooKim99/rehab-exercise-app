# 🩺 Rehab Exercise

> **물리치료사와 대상자를 연결하는 맞춤형 재활운동 관리 웹 애플리케이션**
>
> 물리치료사의 개별 운동 프로그램 처방부터 대상자의 가정운동 수행, 운동 기록 관리, 피드백 제공 및 SOAP 기록까지 하나의 플랫폼에서 관리할 수 있도록 개발한 웹 애플리케이션입니다.

**🌐 Live Demo:** https://rehab-exercise-6484a.web.app/

## 1. 프로젝트 개발 목적 및 개요

재활운동은 의료기관에서의 치료뿐 아니라 대상자가 가정에서도 운동 프로그램을 지속적으로 수행하는 과정이 중요합니다.

그러나 가정운동 프로그램(Home Exercise Program, HEP)은 물리치료사가 대상자의 실제 운동 수행 여부와 진행 상황을 지속적으로 확인하기 어렵다는 한계가 있습니다.

대표적인 문제점은 다음과 같습니다.

- **운동 수행 방법에 대한 이해 부족:** 대상자가 운동 자세와 수행 방법을 정확하게 기억하기 어려움
- **운동 수행 현황 확인의 어려움:** 물리치료사가 대상자의 실제 운동 수행 여부와 이력을 확인하기 어려움
- **개별화된 운동 프로그램 관리의 한계:** 대상자별 운동 종류, 반복 횟수, 세트 수 등을 체계적으로 관리하기 어려움
- **피드백 전달의 비효율성:** 운동 수행 결과에 대한 물리치료사의 피드백을 지속적으로 제공하고 확인하기 어려움

**Rehab Exercise**는 이러한 문제를 개선하기 위해 물리치료사와 대상자를 연결하는 재활운동 관리 플랫폼으로 개발되었습니다.

물리치료사는 대상자의 상태에 맞는 운동 프로그램을 처방하고 수행 현황을 확인할 수 있으며, 대상자는 처방된 운동을 영상으로 확인하고 수행 결과를 기록할 수 있습니다.

특히 초기 프로토타입은 **요통 환자를 위한 가정운동 프로그램**을 중심으로 구성하여 실제 재활운동 관리 과정을 구현하는 데 중점을 두었습니다.

## 2. 주요 기능 상세

### 1) 사용자 인증 및 역할별 화면 구성

Firebase Authentication을 활용하여 사용자 인증 기능을 구현하고, 사용자 역할에 따라 화면과 기능을 구분하였습니다.

**대상자(Patient)**

- 이메일 및 비밀번호 기반 회원가입과 로그인
- 개인 기본정보 및 진단명 확인
- 물리치료사 연결 요청
- 개인별 운동 프로그램 확인
- 운동 수행 기록 및 이력 조회
- 물리치료사 피드백 확인

**물리치료사(Therapist)**

- 물리치료사 계정 로그인
- 담당 대상자 목록 및 정보 관리
- 대상자 연결 요청 관리
- 개인별 운동 프로그램 처방
- 운동 수행 현황 모니터링
- 대상자별 피드백 및 SOAP 기록 관리

### 2) 대상자와 물리치료사 연결 시스템

대상자와 물리치료사가 개별적으로 연결되어 운동 프로그램과 수행 기록을 관리할 수 있도록 구성하였습니다.

- 연결 코드를 활용한 대상자–물리치료사 연결
- 연결 요청 및 승인 상태 관리
- 연결된 대상자 목록 조회
- 담당 대상자 연결 해제
- Cloud Firestore를 활용한 연결 정보 저장 및 유지

### 3) 맞춤형 재활운동 프로그램 처방

물리치료사는 등록된 운동 콘텐츠를 활용하여 대상자에게 적합한 가정운동 프로그램을 구성할 수 있습니다.

**주요 설정 항목**

- 운동 종류 선택
- 운동별 반복 횟수
- 운동별 세트 수
- 운동 수행 관련 안내사항
- 대상자별 운동 프로그램 저장 및 수정

처방된 운동 프로그램은 대상자 화면에 반영되어 개별 운동 계획을 확인할 수 있도록 구성하였습니다.

### 4) 운동 영상 제공 및 수행 기록 관리

대상자는 물리치료사가 처방한 운동 프로그램을 확인하고, 운동 시범 영상을 참고하여 가정운동을 수행할 수 있습니다.

**운동 수행 과정**

1. 개인별 운동 프로그램 확인
2. 운동 방법 및 시범 영상 확인
3. 설정된 반복 횟수와 세트 수에 따라 운동 수행
4. 운동 완료 및 수행 결과 기록
5. 운동 수행 이력 저장

운동 수행 결과는 Cloud Firestore에 저장되어 이후 대상자와 물리치료사가 확인할 수 있습니다.

### 5) 운동 수행 현황 모니터링 및 피드백

물리치료사는 담당 대상자의 운동 수행 기록을 확인하고 개별적인 피드백을 제공할 수 있습니다.

- 대상자별 운동 수행 이력 조회
- 운동 기록을 기반으로 한 피드백 작성
- 일반 피드백 및 특정 운동 기록과 연결된 피드백 관리
- 대상자 화면에서 피드백 확인
- 신규 피드백 알림 및 읽음 상태 관리
- 피드백 확인 이후 읽음 상태 저장

특히 신규 피드백 알림 기능을 통해 대상자가 물리치료사의 피드백을 보다 쉽게 확인할 수 있도록 구성하였습니다.

### 6) SOAP 노트 기반 임상 기록 관리

물리치료사의 임상 기록을 체계적으로 관리하기 위한 SOAP 노트 기능을 구현하였습니다.

SOAP는 다음 네 가지 영역으로 구성되는 임상 기록 방식입니다.

| 구분 | 의미 | 주요 내용 |
|---|---|---|
| S — Subjective | 주관적 정보 | 대상자가 호소하는 증상 및 상태 |
| O — Objective | 객관적 정보 | 측정 및 관찰을 통해 확인한 정보 |
| A — Assessment | 평가 | 대상자의 상태에 대한 임상적 판단 |
| P — Plan | 계획 | 향후 중재 및 관리 계획 |

SOAP 기록의 저장과 수정 이력 관리 기능을 통해 임상 기록의 연속성을 지원하도록 설계하였습니다.

## 3. 요통 환자 대상 가정운동 프로그램

### 1) 운동 콘텐츠 개발 방향

초기 프로토타입은 **요통 환자를 위한 가정운동 프로그램(Home Exercise Program, HEP)**을 중심으로 개발하였습니다.

물리치료사가 대상자의 상태를 고려하여 운동을 선택하고 반복 횟수와 세트 수를 설정하면, 대상자는 처방된 운동을 확인하고 가정에서 수행할 수 있도록 구성하였습니다.

### 2) 운동 콘텐츠 구성

운동 콘텐츠는 요추 및 체간의 가동성, 안정성, 근력 향상 등을 고려하여 구성하였습니다.

| 운동 유형 | 운동 목적 |
|---|---|
| 유연성 및 가동성 운동 | 요추 및 주변 관절의 움직임 개선 |
| 코어 안정화 운동 | 체간 안정성 및 신경근 조절 능력 향상 |
| 근력강화 운동 | 체간 및 엉덩관절 주변 근육의 근력 향상 |
| 기능적 운동 | 일상생활 동작과 관련된 신체 기능 향상 |

초기 운동 라이브러리는 **요통 재활운동 9종**을 중심으로 구성하였습니다.

운동 프로그램의 종류와 수행 조건은 대상자의 상태 및 물리치료사의 임상적 판단을 고려하여 적용하도록 설계하였습니다.

### 3) 운동별 제공 정보

- 운동명
- 운동 수행 목적
- 운동 수행 방법
- 운동 시범 영상
- 반복 횟수 및 세트 수
- 운동 수행 관련 안내사항

## 4. 시스템 구성 및 데이터 관리

Rehab Exercise는 React 기반 프론트엔드와 Firebase 기반 백엔드를 연동하여 구현하였습니다.

| 구성 요소 | 주요 역할 |
|---|---|
| React / TypeScript | 사용자 인터페이스 및 애플리케이션 로직 |
| Firebase Authentication | 사용자 회원가입 및 로그인 |
| Cloud Firestore | 사용자 정보, 연결 관계, 운동 처방, 수행 기록, 피드백 및 SOAP 기록 저장 |
| Firestore Security Rules | 사용자 역할 및 데이터 접근 권한 제어 |
| Firebase Hosting | 웹 애플리케이션 배포 |
| GitHub Actions | GitHub 코드 변경에 따른 자동 빌드 및 배포 |

사용자별 데이터 접근 권한을 구분하여 대상자와 물리치료사가 자신의 역할에 맞는 기능을 사용할 수 있도록 설계하였습니다.
