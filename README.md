# Rehab Exercise

### 요통 환자의 가정운동 수행과 물리치료사의 운동 관리를 지원하는 웹 애플리케이션

## 1. 프로젝트 소개

**Rehab Exercise**는 재활운동이 필요한 대상자가 가정에서도 체계적으로 운동을 수행하고, 물리치료사가 대상자의 운동 수행 현황을 확인하고 관리할 수 있도록 개발한 웹 기반 재활운동 관리 플랫폼입니다.

본 프로젝트는 **요통 환자를 위한 가정운동 프로그램(Home Exercise Program, HEP)**을 중심으로 기획되었습니다.

일반적으로 재활운동은 의료기관에서의 치료뿐 아니라 대상자의 지속적인 자가운동 수행이 중요합니다. 그러나 대상자가 운동 방법을 정확하게 기억하거나, 처방된 운동을 지속적으로 수행하고 기록하는 데 어려움이 있을 수 있습니다.

이러한 문제를 해결하기 위해 운동 안내, 시범 영상, 개인별 운동 처방, 수행 기록 및 피드백 기능을 하나의 웹 애플리케이션으로 통합하였습니다.

대상자는 처방된 운동을 확인하고 수행 결과를 기록할 수 있으며, 물리치료사는 대상자의 운동 이력을 확인하고 개별 운동 프로그램을 관리할 수 있습니다.

## 2. 개발 목적

- **가정운동 수행 지원:** 대상자가 시간과 장소에 관계없이 처방된 재활운동을 확인하고 수행할 수 있도록 지원
- **운동 방법의 이해도 향상:** 운동별 수행 방법과 시범 영상을 제공하여 올바른 운동 수행 지원
- **운동 수행 기록 관리:** 운동 완료 여부와 수행 이력을 체계적으로 저장하고 확인
- **개인별 운동 프로그램 제공:** 물리치료사가 대상자의 상태에 맞게 운동 종류, 횟수 및 세트를 설정
- **물리치료사의 대상자 관리:** 대상자별 운동 수행 현황을 확인하고 피드백을 제공할 수 있는 관리 환경 구축

## 3. 주요 사용자

| 구분 | 사용자 | 주요 역할 |
|---|---|---|
| 대상자 (Patient) | 재활운동이 필요한 사용자 | 운동 프로그램 확인, 시범 영상 시청, 운동 수행 및 기록 관리 |
| 물리치료사 (Therapist) | 대상자의 재활운동을 관리하는 사용자 | 대상자 관리, 운동 프로그램 처방, 수행 기록 확인 및 피드백 제공 |

본 애플리케이션은 사용자 역할에 따라 서로 다른 화면과 기능을 제공합니다.

## 4. 주요 기능

### 4.1 대상자 기능

**① 회원가입 및 로그인**
- 사용자 계정 생성 및 로그인
- 개인별 정보 확인 및 관리
- 연결 코드를 통한 담당 물리치료사 연결

**② 재활운동 프로그램 확인**
- 물리치료사가 처방한 개인별 운동 프로그램 조회
- 운동 종류, 반복 횟수 및 세트 수 확인
- 운동별 수행 방법 및 주의사항 확인

**③ 운동 시범 영상 제공**
- 운동별 시범 영상 확인
- 영상 및 운동 안내를 참고한 가정운동 수행

**④ 운동 수행 기록**
- 처방된 운동의 수행 및 완료 기록
- 날짜별 운동 수행 이력 확인
- 개인별 운동 기록 관리

**⑤ 물리치료사 피드백 확인**
- 담당 물리치료사가 작성한 피드백 조회
- 신규 피드백 알림 확인
- 피드백 읽음 상태 관리

### 4.2 물리치료사 기능

**① 대상자 관리**
- 담당 대상자 목록 및 기본정보 확인
- 연결 요청 및 연결 상태 관리
- 대상자별 정보 관리

**② 재활운동 프로그램 처방**
- 운동 라이브러리에서 운동 선택
- 대상자별 운동 프로그램 구성
- 운동별 반복 횟수 및 세트 수 설정
- 처방된 운동 프로그램의 저장 및 관리

**③ 운동 수행 현황 모니터링**
- 대상자별 운동 수행 기록 조회
- 운동 수행 이력 및 진행 현황 확인

**④ 피드백 제공**
- 대상자의 운동 수행 결과 확인
- 대상자별 피드백 작성 및 관리
- 운동 기록과 연계한 피드백 제공

**⑤ 대상자 평가 및 임상 기록**
- 대상자 평가 정보 기록 및 관리
- SOAP 형식의 임상 기록 작성
- SOAP 기록의 수정 이력 관리

## 5. 재활운동 콘텐츠 구성

### 5.1 운동 프로그램 개발 방향

본 프로젝트는 초기 개발 단계에서 요통 환자를 대상으로 한 가정운동 프로그램을 중심으로 구성하였습니다.

물리치료사가 대상자의 상태에 따라 운동을 선택하고 반복 횟수와 세트 수를 설정하면, 대상자는 웹 애플리케이션에서 해당 프로그램을 확인하고 운동을 수행하는 방식입니다.

운동 콘텐츠는 유연성 및 가동성 운동, 코어 안정화 운동, 근력강화 운동 등을 중심으로 기획하였습니다.

### 5.2 운동 콘텐츠 예시

| 운동 유형 | 운동 예시 |
|---|---|
| 유연성 및 가동성 운동 | 무릎 가슴 당기기, 고양이-낙타 운동, 허리 회전 운동 |
| 코어 안정화 운동 | 복부 브레이싱, 버드독, 데드버그 |
| 근력강화 운동 | 브리지, 클램셸, 옆으로 누워 다리 들기 |
| 기능적 운동 | 의자에서 일어서기, 스쿼트 |

※ 위 표는 초기 콘텐츠 기획 과정에서 검토한 운동 예시이며, 실제 애플리케이션에 등록된 운동 목록과는 차이가 있을 수 있습니다.

### 5.3 운동별 제공 정보

- 운동명 및 운동 목적
- 운동 시작 자세
- 운동 수행 방법
- 운동 반복 횟수 및 세트 수
- 운동 수행 시 주의사항
- 운동 시범 영상 또는 안내 자료

## 6. 가정운동 프로그램 이용 과정

### 6.1 물리치료사

1. 물리치료사 계정으로 로그인
2. 담당 대상자 연결 및 정보 확인
3. 운동 라이브러리에서 운동 선택
4. 대상자별 운동 프로그램 구성 및 처방
5. 대상자의 운동 수행 기록 확인
6. 필요에 따라 피드백 작성 및 제공

### 6.2 대상자

1. 대상자 계정으로 로그인
2. 담당 물리치료사 연결
3. 처방된 재활운동 프로그램 확인
4. 운동 시범 영상 및 수행 방법 확인
5. 설정된 횟수와 세트에 따라 운동 수행
6. 운동 완료 기록 저장
7. 운동 수행 이력 및 물리치료사 피드백 확인

## 7. 개발 기술 및 시스템 구성

### 7.1 사용 기술

| 구분 | 기술 |
|---|---|
| 개발 환경 | Google AI Studio |
| 프론트엔드 | React, TypeScript, Vite |
| 백엔드 서비스 | Firebase |
| 사용자 인증 | Firebase Authentication |
| 데이터베이스 | Cloud Firestore |
| 파일 저장 | Firebase Storage |
| 웹 호스팅 | Firebase Hosting |
| 버전 관리 | Git, GitHub |
| 자동 배포 | GitHub Actions |

### 7.2 시스템 구성

본 시스템은 대상자와 물리치료사의 사용자 역할을 구분하여 운영됩니다.

**Firebase Authentication**을 통해 사용자 인증을 처리하고, **Cloud Firestore**를 활용하여 사용자 정보, 대상자 연결 정보, 운동 처방, 운동 수행 기록 및 피드백 데이터를 저장하고 관리합니다.

또한 **Firestore Security Rules**를 통해 사용자 역할과 연결 관계에 따른 데이터 접근 권한을 제어합니다.

프론트엔드는 React와 TypeScript를 기반으로 개발하였으며, GitHub Actions와 Firebase Hosting을 이용해 웹 애플리케이션을 배포합니다.
